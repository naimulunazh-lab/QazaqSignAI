# QazaqSign AI - MVP архитектурасы

Многопользовательский запуск и публикация: [DEPLOY.md](DEPLOY.md).

Динамические жесты, лицо и положение головы: [dataset/TEMPORAL_DATASET.md](dataset/TEMPORAL_DATASET.md). Для записи обучающих последовательностей откройте `capture.html` через работающий локальный сервер.

Бұл — қазақ ым тілін үйретуге арналған статикалық веб-MVP. Оны локалдық HTTP серверден ашыңыз: `npx serve .` немесе VS Code Live Server. Камера браузердегі `localhost`/HTTPS контекстінде ғана жұмыс істейді.

## Құрылым

```
index.html                  UI және MediaPipe CDN
assets/styles.css           Адаптивті, қазақы түстер мен оюға негізделген дизайн
data/mock-kzsl-dataset.js   Оқу бағдарламасы және алмастырылатын fake dataset
src/app.js                  Күй, навигация, сабақтар, прогресс
src/recognizer.js           Камера/landmarks провайдері + модель адаптері
```

## Нақты модельді қосу

1. Нақты landmark CSV-ді `dataset/landmarks.csv` ретінде салыңыз. Толық схема мен бір командалы оқыту нұсқауы [dataset/README.md](dataset/README.md) ішінде.
2. Скрипт білекке қатысты орталықтандыру мен алақан өлшеміне нормалауды web-кодпен бірдей орындайды.
3. Статикалық қимыл үшін `training/train.py`, ал қозғалыс, мимика және қолдың бетке қатысты орналасуы үшін `training/train_temporal.py` браузерге дайын TensorFlow.js моделін автоматты экспорттайды.
4. Модель бар кезде `TemporalModelAdapter` өздігінен жүктеледі; модель жоқ кезде `MockModelAdapter` демонстрацияны жұмыс істетеді. Екеуінің интерфейсі бірдей:

```js
predict(landmarks, target) // => { score: 0..100, label, message }
```

`GestureRecognizer` тек камера және landmark табуды басқарады, сондықтан AI-модель, API немесе датасетке тәуелсіз. Өндірісте бағалауға уақыт терезесін (20–40 кадр), confidence threshold және жеке «қайталап көрсет» кері байланысын қосыңыз.

## Қауіпсіздік және қолжетімділік

Камера кадрлары осы MVP-де серверге жіберілмейді: олар браузерде MediaPipe арқылы талданады. Нақты нұсқада айқын consent, дерек сақтау саясаты, экрандық мәтін және пернетақта арқылы толық басқаруды міндетті түрде тексеріңіз.
